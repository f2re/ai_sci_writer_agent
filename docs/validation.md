## Реальная визуальная проверка DOCX

Тестовый макет с двуязычной шапкой, таблицей, дробью, кириллицей и полной
библиографией экспортирован в DOCX, отрендерен LibreOffice в PDF/PNG. Просмотрены
обе страницы. Обнаруженная проблема таблицы при общем Pandoc writer исправлена:
основной документ создаёт python-docx, из отдельной математической конверсии
вставляется только OMML. Таблица, дробь, текст и библиография читаются без обрезания.
Макет явно искусственный, научных результатов не содержит и не включён в репозиторий.

**XeLaTeX-компиляция не подтверждена:** доступной среде недостаёт `xelatex.fmt`.
Экспорт `.tex` проверен структурно, в том числе против `\\input` и обхода через
`^^`-раскодирование; автоматический запуск TeX не производится.

- 32 теста `unittest`: русская пунктуация, десятичные числа и сокращения; исключение формул,
  ссылок и цитат; защищённые термины; профили ритма; UTF-16 и разбиение текста для сервиса.
- Проверки ошибок HTTP/JSON, частичных ответов, запрета незапрошенной удалённой передачи,
  отклонения устаревших отчётов и расхождения исходного ответа со сводным статусом.

- Изменение текста/источников делает проверки устаревшими. Писатель не может выступить
  собственным независимым рецензентом. Без образцов автора запрещена выдуманная оценка сходства.
- Незапущенный сервис нельзя сделать завершённым простым редактированием сводного JSON.
  Эмпирическая запись без исполнения и журналов, незакрытый маркер и выход экспорта за run
  через symlink отклоняются.
- `sci-writer --help` и `doctor`; все пути ролей и ключевые ссылки документации проверены.
- 6 JSON-примеров из `artifact-examples.md` проверены по схемам; 3 review-объекта созданы
  исполняемым примером с реальными хешами. Содержательная готовность этих примеров
  намеренно не подтверждается.

Локальные HTTP tests используют fixture-сервер. Он моделирует протокол и ошибки,
но не является настоящим LanguageTool. Тестовые источники не включены в научный каталог

## Существенные границы

В этой работе не выполнялось написание статьи по конкретной научной теме: такая тема,
данные и авторские образцы ещё не переданы. Не вызывались платный Главред, коммерческие
AI-детекторы и платные библиографические базы. Не воспроизводились benchmark-результаты
рассмотренных внешних агентских систем.

OpenAlex и импорт проверены программными тестами, без утверждения о проведённом
полном поиске по реальным каталогам. Платформенные адаптеры проверены структурно;
ручные сеансы во всех IDE не выполнялись. MCP проверяет транспорт и функции движка,
а не научное качество будущего автора-LLM. Английская аннотация получает базовую
диагностику; полноценный английский научный редактор не заявляется.

JSON-контракты и хеши проверяют согласованность, а не истинность научных утверждений.
Реальный доступ к источнику, независимость рецензента и корректность интерпретации требуют
добросовестной работы людей и агентов. Импорт Главреда — письменное подтверждение
исполнителя, а не криптографическое свидетельство вызова чужого сервера.

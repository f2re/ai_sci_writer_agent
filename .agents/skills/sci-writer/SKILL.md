# Вход в Scientific Writer

Это обнаруживаемый вход в систему, а не дополнительная исследовательская роль.
Работать из корня этого checkout; навыку нужны файлы репозитория и CLI либо подключённый MCP.

1. Прочитать [общие правила](../../../AGENTS.md),
   [координатор](../../../agents/00-orchestrator.md) и [workflow](../../../config/workflow.json).
2. Для нового исследования создать `sci-writer init runs/<id> --topic "..."`;
   для существующего запуска сначала получить `sci-writer status runs/<id>`.
3. Вызвать `sci-writer next runs/<id>`; загрузить только указанный текущим этапом модуль
   из восьми рабочих навыков и необходимые входные артефакты. Не загружать все навыки заранее.
4. Выполнить исследование/редактуру по заданию, затем `validate` и `complete ... --actor <реальный-сеанс>`.
5. Пройти обязательный пятый этап и три профиля рецензирования; главный рецензент работает последним.
   После его заключения вызвать `finalize`; незавершённую работу выдавать через `export-draft`.

Выбирать execution_profile и review_mode независимо по фактическим возможностям среды.
`strict_local` не требует Docker, если разрешённый обязательный сервис доступен иным способом.
Без внешнего runtime использовать `offline_sandbox`; без независимых сеансов —
`single_session_self_audit`. Сохранять ограничения, не выдавать эти режимы за полную готовность.

Не читать `research-archive/` и все справочники для обычной работы над статьёй.
Состав ролей, этапов и выходов брать только из workflow; здесь он не дублируется.
Установку, форматы и команды уточнять по [README](../../../README.md);
платформенные ограничения — по [совместимости](../../../docs/compatibility.md).
